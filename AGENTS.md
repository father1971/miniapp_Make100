# Инструкции для Агента / Agent Rules

- Всегда отвечать пользователю исключительно на русском языке. (Always communicate with the user exclusively in Russian.)
- Все проектные обсуждения, комментарии, коммиты и документация должны вестись на русском языке, если это возможно.
- Если у Агента появляются какие-либо новые идеи, улучшения, рефакторинг или предложения, он ОБЯЗАН сначала предложить их пользователю в чате и дождаться его явного разрешения на реализацию. Самостоятельное внедрение несогласованных изменений или улучшений строго запрещено.
- После выполнения задания, описанного в промте, Агент ОБЯЗАН перечитать промт еще раз и проверить себя, все ли пункты были выполнены. Если что-то сделать невозможно, Агент должен прямо сообщить об этом пользователю и объяснить причину.
- Обязательное правило описания коммитов: После каждого изменения кода Агент ОБЯЗАН писать подробный коммит (делать git commit) исключительно на русском языке — как в тестовой ветке `main`, так и при релизе/слиянии в `prod`. Сообщение коммита обязано содержать три структурированных блока:
  1. Понятный заголовок (`feat: ...` / `fix: ...`).
  2. Блок `[Зачем и почему сделано]`: контекст задачи, предыстория, какую проблему решаем и с какой целью.
  3. Блок `[Что конкретно изменено по файлам]`: детальный маркированный список изменений по каждому изменённому файлу (компоненты, классы, логика, стили, функции).
  4. Блок `[Результат]`: как это теперь работает на практике (поведение на разных устройствах/экранах/сценариях).
  Чтобы в консоли Windows не срезались символы и спецзнаки, сообщение коммита должно передаваться без искажения экранирования.
- Обязательное правило локализации интерфейса: Если в интерфейс игры добавляется любая надпись (название окна, заголовки, кнопки, табы, подсказки, всплывающие сообщения, текстовые поля и т.д.), Агент ОБЯЗАН автоматически добавлять переводы этой надписи на ВСЕ поддерживаемые языки игры в `src/translations.ts` (и интерфейс `TranslationData`) и использовать ключ локализации `t` в компонентах, чтобы надпись всегда отображалась на выбранном пользователем языке без исключений.
- Обязательное правило верификации фактов кодовой базы (Запрет догадок): Агенту строго запрещено делать утверждения о кодовой базе (количестве поддерживаемых языков, структуре данных, названиях функций, константах, стилях и настройках) по приблизительной памяти. Перед любым утверждением или отчётом Агент ОБЯЗАН сначала проверить реальные файлы (`read_file`, grep, поиск в AST) и отвечать только на основе фактически проверенных данных.
- Обязательное правило публикации в продакшн (боевую версию): Публиковать в боевую версию (Production / ветка `prod` / боевой бот `@Make_100_Bot` / Cloudflare Pages `https://make100-3ow.pages.dev` / воркер `make100-backend-prod`) фронтенд и бэкенд разрешено ТОЛЬКО по прямому и явному указанию пользователя. Вся текущая разработка, тестирование и правки ведутся исключительно в тестовой среде (ветка `main` / тестовый бот `@Test_Make100_bot` / GitHub Pages `https://father1971.github.io/miniapp_Make100/`).
