# Инструкции для Агента / Agent Rules

- Всегда отвечать пользователю исключительно на русском языке. (Always communicate with the user exclusively in Russian.)
- Все проектные обсуждения, комментарии, коммиты и документация должны вестись на русском языке, если это возможно.
- Если у Агента появляются какие-либо новые идеи, улучшения, рефакторинг или предложения, он ОБЯЗАН сначала предложить их пользователю в чате и дождаться его явного разрешения на реализацию. Самостоятельное внедрение несогласованных изменений или улучшений строго запрещено.
- После выполнения задания, описанного в промте, Агент ОБЯЗАН перечитать промт еще раз и проверить себя, все ли пункты были выполнены. Если что-то сделать невозможно, Агент должен прямо сообщить об этом пользователю и объяснить причину.
- После каждого изменения кода Агент ОБЯЗАН писать коммит (делать git commit) с описанием изменений на русском языке.
